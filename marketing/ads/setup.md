# Підключення реклами: покрокові інструкції (бюджет $500, старт 24.11, пік 1.12)

Усе нижче робите ви в кабінетах; сюди-туди передаються лише ID (їх можна вставляти в адмінку), паролі й токени нікому не надсилайте.

## Крок 0. Один раз у Cloudflare D1 (обов'язково, першим)
1. dash.cloudflare.com → Storage & Databases → D1 → ваша база → Console.
2. Виконайте рядки з `docs/d1-console-0010.sql` **по одному** (кожен рядок окремою командою, лише одна інструкція за раз).
3. Без цього сайт усе одно працює, але мітки реклами (UTM) в замовленнях не зберігатимуться.

## Крок 1. Meta (Facebook + Instagram)
**1.1 Рекламний акаунт і оплата**
1. business.facebook.com → Налаштування бізнесу → Облікові записи → Рекламні акаунти → Додати → «Створити новий». Валюта USD, часовий пояс Київ.
2. Додайте себе з повним доступом і сторінку ReeAdvent.fun та Instagram `reeadvent` (їх уже підключено).
3. Рекламний акаунт → Налаштування оплати → додайте картку.

**1.2 Піксель**
1. business.facebook.com → Events Manager (Менеджер подій) → «Підключити джерела даних» → Інтернет → назва «ReeAdvent» → Meta Pixel.
2. Адреса сайту `https://reeadvent.fun`. Спосіб налаштування: «Додати код вручну» (код ставити не треба, він уже в сайті), просто скопіюйте **ID піксела** (15–16 цифр).
3. В адмінці: **Соцмережі й реклама → Реклама → Відстеження → ID піксела Meta → Зберегти відстеження**. На сайті з'явиться банер cookies.
4. У налаштуваннях піксела вимкніть **«Автоматичне розширене зіставлення»** (Automatic advanced matching): ми не передаємо імен і пошт, це записано в політиці конфіденційності.

**1.3 Верифікація домену**
1. Налаштування бізнесу → Безпека бренду → Домени → Додати `reeadvent.fun`.
2. Виберіть метод DNS TXT: Meta покаже запис. У Cloudflare → ваш домен → DNS → Add record: тип TXT, ім'я `@`, значення з Meta. Поверніться й натисніть «Верифікувати».
3. Events Manager → Aggregated Event Measurement → пріоритет подій: 1 Purchase, 2 InitiateCheckout, 3 ViewContent.

**1.4 Перевірка піксела**
1. Events Manager → Test Events → введіть `https://reeadvent.fun`, відкрийте сайт, натисніть «Прийняти всі»: ви маєте побачити PageView і ViewContent.
2. Створіть тестове замовлення з промокодом 100% (він без оплати): InitiateCheckout має з'явитися. Подія Purchase надсилається лише для платних замовлень із сумою більше нуля.

**1.5 Кампанії ($270 на Meta до 1.12)**
1. Ads Manager → Створити → ціль **Продажі** (Sales), конверсія на сайті, подія **Purchase** (якщо піксел ще «не навчений», на перші 3 дні оберіть InitiateCheckout, коли набереться 10–15 покупок, перемкніть на Purchase).
2. **Кампанія 1 «ua_cold»**, бюджет $12/день: Україна, 22–45, мова будь-яка, Advantage+ аудиторія. 3 оголошення: Reel `02-reel.mp4`, карусель «Як це працює», картка пари.
3. **Кампанія 2 «eu_ua»**, бюджет $10/день: країни PL, DE, CZ, SK, IE, NL, IT, ES, LT, мова **українська**, 22–45. Ті самі три оголошення.
4. З 27.11 **Кампанія 3 «retarget»**, $6/день: аудиторія «Відвідувачі сайту 14 днів» і «Взаємодія з Instagram 30 днів», виключити купивших. Оголошення: «Ще можна встигнути».
5. Посилання в кожному оголошенні беріть з адмінки (Реклама → «Посилання з мітками»): джерело `meta`, кампанія `ua_cold` / `eu_ua` / `retarget`, креатив `reel1` і т.д. Вставте в поле «Веб-сайт URL» оголошення.
6. Тексти: `marketing/ads/copy.md`. Розміщення: Advantage+ (автоматично). Не змінюйте кампанії перші 48 годин.

## Крок 2. Google Analytics 4
1. analytics.google.com → Адміністрування → Створити → Ресурс «ReeAdvent», часовий пояс Київ, валюта UAH.
2. Потік даних → Веб → `https://reeadvent.fun` → скопіюйте **Measurement ID** (`G-XXXXXXXXXX`).
3. В адмінці: Реклама → Відстеження → GA4 → Зберегти.
4. Через добу GA4 → Звіти → Реальний час покаже відвідувачів (лише тих, хто прийняв cookies). Події `begin_checkout` і `purchase` позначте «ключовими» (Адміністрування → Події → Позначити як ключову).

## Крок 3. Google Ads ($110 на Search)
1. ads.google.com → створити акаунт, у налаштуваннях оберіть **«Перейти в режим експерта»** (Expert mode), не «Розумна кампанія».
2. **Конверсія:** Цілі → Конверсії → Нова → Веб-сайт → «Вручну додати код» → категорія Покупка, значення «Використовувати різні значення», валюта UAH, враховувати «Кожна». Збережіть: у вікні «Тег Google» візьміть **Conversion ID** (`AW-1234567890`) і **мітку конверсії** (рядок після `/` у send_to).
3. В адмінці: Реклама → Відстеження → Google Ads ID і Мітка конверсії → Зберегти.
4. **Пов'язати з GA4:** Google Ads → Інструменти → Пов'язані акаунти → Google Analytics → Зв'язати.
5. **Кампанія Search:** Створити → ціль Продажі → тип Пошукова мережа → без розумної автоматизації спершу: стратегія «Максимізувати кліки» зі стелею ставки $0,35. Бюджет $12/день.
6. Локації: Україна (+ окремою кампанією Польща/Німеччина/Чехія з мовою «українська», $6/день). Мови: українська, англійська.
7. Ключові слова (точна/фразова відповідність): «адвент календар для пари», «адвент календар для коханої», «адвент календар для коханого», «подарунок на новий рік для дівчини», «сюрприз для коханої», `advent calendar for couples`, `romantic advent calendar`. Мінус-слова: безкоштовно, скачати, шоколад, діти, своїми руками, дитячий.
8. Оголошення й заголовки: з `marketing/ads/copy.md`. Фінальний URL з UTM: джерело `google`, кампанія `search_ua`.

## Крок 4. Мікроінфлюенсери ($70)
1. Адмінка → **Промокоди** → створіть код на кожного блогера (наприклад `ANNA10`, знижка 10%).
2. У пропозиції (`copy.md`) дайте блогеру посилання з міткою: джерело `influencer`, креатив = ім'я блогера. Звіт у «Результати» покаже, хто привів покупців.
3. Витрати за блогерів вносьте у «Витрати» (канал `influencer`).

## Крок 5. Щоденна рутина (10 хв, 9:00)
1. Рекламні кабінети: скопіюйте витрати за вчора й додайте в адмінці (Реклама → Витрати).
2. Подивіться «Результати»: CPA і ROAS за джерелами.
3. Правило: креатив/аудиторію вимикаєте, якщо витратили вдвічі більше допустимого CPA без покупки; 60% залишку бюджету віддаєте найкращому.
4. Лист чи коментарі: відповідайте в першу годину.
