# Кампанії Meta через API

Workflow **«Meta Ads — кампанії через API (на паузі)»** (`.github/workflows/meta-ads.yml`, скрипт `tools/meta-ads.mjs`) створює кампанії з `marketing/ads/meta-campaigns.json`.
- **Усе на паузі.** Вмикаєте в Ads Manager самі.
- **Повторний запуск** не дублює кампанії: кампанії з такою назвою пропускаються.

## Один раз: токен
1. Перевірте застосунок. business.facebook.com → **Налаштування** → **Облікові записи → Застосунки**: має бути застосунок, через який публікується Instagram.
2. Відкрийте системного користувача. **Користувачі → Системні користувачі** → `reeadvent-web` (або створіть нового з роллю «Адміністратор»).
3. **Призначте ресурси**:
   - рекламний акаунт ReeAdvent: **«Керування кампаніями»** (повний контроль);
   - сторінку Facebook ReeAdvent: «Створення реклами»;
   - Instagram reeadvent;
   - набір даних ReeAdvent.Fun (2111183512849298).
4. **Згенеруйте новий токен**: виберіть застосунок, строк «Ніколи» і дозволи `ads_management`, `ads_read`, `business_management`, `pages_show_list`, `pages_read_engagement`, `instagram_basic`.
5. Збережіть токен у **GitHub**: репозиторій → Settings → **Secrets and variables → Actions** → New repository secret. Назва: `META_ADS_TOKEN`, значення — токен. **Не надсилайте токен у чат.**
6. **Переведіть застосунок у режим «Live»** (у відкритий доступ). Застосунок у режимі розробки не може створювати креативи для реклами: Meta відповідає «Допис із рекламними матеріалами створено додатком в режимі розробки».
   - developers.facebook.com → **Мої застосунки** → ваш застосунок → **Налаштування застосунку → Основне**:
     - URL політики конфіденційності: `https://reeadvent.fun/legal/privacy.html`;
     - умови використання: `https://reeadvent.fun/legal/offer.html`;
     - видалення даних: інструкція `https://reeadvent.fun/legal/privacy.html`;
     - категорія;
     - значок 1024×1024: `https://reeadvent.fun/assets/icon-512.png` у збільшеному варіанті.
   - Збережіть зміни → угорі сторінки перемикач **«Режим застосунку: Розробка → Live»**.

Якщо запуск обірвався посередині (наприклад, на креативах), просто запустіть **create** ще раз: наявні кампанія й група оголошень не дублюються, дотворюються лише відсутні оголошення.

## Запуск
1. Actions → «Meta Ads — кампанії через API» → Run workflow.
2. Спершу **mode = check**. Нічого не створюється: скрипт показує знайдений рекламний акаунт, сторінку, Instagram, аудиторію «Купили» й перевіряє параметри.
3. Потім **mode = create**. Створюються кампанії, групи оголошень, креативи й оголошення **на паузі**.
4. Ads Manager → перевірте → **Увімкнути**.

Якщо доступних рекламних акаунтів чи сторінок кілька, вкажіть ID у полях `ad_account` / `page_id`.

Що змінити (бюджети, країни, тексти, креативи) — у `meta-campaigns.json`.

## Майданчики (Threads)
Нові групи оголошень створюються з майданчиками з `placements` у `meta-campaigns.json`: Facebook, Instagram, Messenger, Threads. Threads Meta дозволяє лише разом з Instagram.
Для наявних груп: спершу **mode = placements-check** (лише перевірка), потім **mode = placements** (оновлює тільки майданчики; бюджет, статус і решта таргетингу не змінюються).
